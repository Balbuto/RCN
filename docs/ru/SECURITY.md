# Безопасность и ограничения

## Исправления безопасности в v3

- пользовательский ввод не встраивается напрямую в inline Python-код;
- JSON-конфигурация обновляется атомарно через временный файл и `os.replace()`;
- для JSON используется file lock;
- параллельные `update/apply` сериализуются через `flock`;
- обновление `ipset` выполняется атомарно через временный set и `swap`.

## Что важно в эксплуатации

### Скрипт работает от root
Это необходимо для управления `iptables`, `ipset` и `systemd`.

### GeoIP по странам зависит от внешнего источника CIDR
Используется `ipdeny.com`.
Если источник недоступен:
- будет использован локальный кэш, если он уже есть;
- если кэша нет, обновление country-set не выполнится.

### IPv6 не поддерживается
Текущая версия работает только с IPv4 (`family inet`).

### Country GeoIP — это CIDR-фильтрация, а не MaxMind GeoIP DB
Привязка идёт по опубликованным country-block спискам.

### Не рекомендуется запускать на сервере, где `iptables` полностью управляется внешней системой
Например:
- orchestration-layer;
- firewall manager в панели;
- CM-система, полностью перезаписывающая `iptables`.
