# Переход на v3.1

## Что изменилось

В старых версиях проекта были следующие проблемы:
- `ipset` очищался до успешной загрузки нового списка;
- при повторном применении накапливались дубли `iptables`-правил;
- конфликтовали `cron` и фоновый демон;
- пользовательский ввод обрабатывался частично небезопасно;
- при uninstall удалялись глобальные firewall-файлы;
- GeoIP по странам был заявлен, но не применялся как реальный country-фильтр.

В v3 появилась текущая схема атомарного обновления, systemd и CIDR-фильтрации. В v3.1 дополнительно защищён весь цикл чтения, изменения и записи JSON-конфигурации, безопасно нормализуются legacy-значения boolean и IPv6-записи отклоняются до передачи в IPv4-only `ipset`.

## Перед обновлением

1. Сохраните `/etc/rkn-watcher/`, если в нём есть нужная конфигурация.
2. Удалите IPv6-адреса и сети из `whitelist.json` и `blacklist.json`: v3.1 принимает только IPv4-записи.
3. При ручном редактировании JSON используйте для `enabled` JSON-значения `true` и `false`.

## Рекомендуемый способ перехода

### Вариант 1. Обновление существующей установки v3

```bash
cd RCN
git pull
sudo ./installer.sh install
```

При запросе выберите сохранение текущей конфигурации, затем выполните:

```bash
sudo rkn-watcher apply
sudo rkn-watcher status
```

### Вариант 2. Чистая установка после старого релиза

1. удалить старую версию;
2. установить v3.1 через `sudo ./installer.sh`;
3. перенести только нужные IPv4 allow/deny-записи и коды стран;
4. проверить список стран до включения GeoIP.

## Что проверить после миграции

```bash
sudo rkn-watcher status
sudo iptables -L INPUT -v -n
sudo ipset list TSPUIPS | head
sudo ipset list GOVIPS | head
sudo ipset list GEOIP_COUNTRIES_ALLOW | head
```

Для проверки файлов скачанного релиза перед установкой:

```bash
sha256sum -c SHA256SUMS
```
