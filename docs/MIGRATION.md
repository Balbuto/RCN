# Миграция со старых версий

## Что изменилось концептуально

Старые версии проекта содержали следующие проблемы:

- очистка `ipset` до успешной загрузки нового списка;
- дублирование `iptables`-правил при повторном применении;
- конфликт `cron` и фонового демона;
- частично небезопасная работа с пользовательским вводом;
- удаление глобальных firewall-файлов при uninstall;
- заявленная, но фактически неработающая GeoIP-фильтрация по странам.

Версия v3 устраняет эти проблемы.

## Рекомендуемый способ перехода

### Вариант 1. Чистая установка

1. удалить старую версию;
2. поставить v3 из этого репозитория через `sudo ./installer.sh`;
3. заново настроить allow/deny и список стран.

### Вариант 2. Обновление с сохранением логики

Если нужно аккуратно перейти:

1. сохранить старые значения whitelist/blacklist;
2. отключить старую автозагрузку и старый daemon/cron;
3. установить v3;
4. перенести только нужные пользовательские данные в новые конфиги;
5. выполнить `sudo rkn-watcher apply`.

## Что обязательно проверить после миграции

```bash
sudo rkn-watcher status
sudo iptables -L INPUT -v -n
sudo ipset list TSPUIPS | head
sudo ipset list GOVIPS | head
sudo ipset list GEOIP_COUNTRIES_ALLOW | head
```

## Изменения в поведении

### Было
- GeoIP по странам мог числиться включённым, но фактически не фильтровал по странам.

### Стало
- country CIDR реально загружаются и применяются через `ipset`.

### Было
- обновление могло оставить защиту пустой при временной сетевой ошибке.

### Стало
- старый рабочий список сохраняется, пока новый полностью не подготовлен.

### Было
- автообновление могло идти из двух источников одновременно.

### Стало
- только `systemd timer`.
