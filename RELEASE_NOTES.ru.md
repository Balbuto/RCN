# Примечания к релизу — RKN Watcher v3.1.0

## Основное

Релиз `v3.1.0` — обновление надёжности и сопровождения v3. Он предотвращает потерю изменений JSON-конфигурации, безопасно обрабатывает legacy-значения boolean и явно проверяет границу IPv4-only реализации `ipset`.

## Исправлено в v3.1.0

- Lock JSON-конфигурации теперь покрывает весь цикл чтения, изменения и записи. Параллельные вызовы `config_tool.py` больше не перезаписывают добавления или удаления друг друга.
- `enabled: "false"` и другие поддерживаемые legacy-представления boolean нормализуются корректно; непустая строка больше не включает GeoIP по ошибке.
- IPv6-адреса и сети последовательно отклоняются в меню, конфигураторе и пути применения GeoIP. Проект пока создаёт только IPv4 `ipset`-наборы.
- `SHA256SUMS` пересоздан для фактически отслеживаемых файлов релиза и больше не ссылается на отсутствующие файлы.

## Документация и тесты

- Русская и английская документация по релизу, конфигурации, безопасности, миграции, диагностике, тестам и публикации обновлена для v3.1.
- Добавлены mock-проверки параллельного изменения конфигурации, нормализации legacy boolean и отклонения IPv6.
- GitHub Actions теперь проверяет `SHA256SUMS` после синтаксических и mock-тестов.

## Обновление с v3.0.x

1. Обновите рабочую копию репозитория.
2. Убедитесь, что в `whitelist.json` и `blacklist.json` остались только IPv4-записи.
3. Запустите обновление через установщик:

```bash
git pull
sudo ./installer.sh install
```

Существующая JSON-конфигурация остаётся поддерживаемой. При ручном редактировании для `enabled` используйте JSON-значения `true` и `false`.

## Минимальный сценарий публикации

```bash
bash -n installer.sh rkn-watcher.sh
python3 -m py_compile config_tool.py geoip_apply.py
chmod +x tests/run_tests.sh
./tests/run_tests.sh
sha256sum -c SHA256SUMS
git add .
git commit -m "Release v3.1.0"
git tag -a v3.1.0 -m "RKN Watcher v3.1.0"
git push origin main v3.1.0
```

## Минимальный сценарий установки пользователем

```bash
git clone https://github.com/Balbuto/RCN.git
cd RCN
chmod +x installer.sh rkn-watcher.sh
sudo ./installer.sh
```
