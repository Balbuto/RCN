# RKN Watcher

## Описание
RKN Watcher — это комплексное решение для защиты сервера от DPI-блокировок и GeoIP фильтрации. Система автоматически загружает и применяет актуальные списки IP-адресов и подсетей, используемых для блокировки трафика, и позволяет гибко настраивать правила фильтрации.

## Возможности
🔒 TSPUBLOCK — блокировка подсетей CyberOK Skipa

🏛️ GOVIPS — блокировка IP-адресов государственных органов

🌍 GeoIP фильтрация — белый список стран, IP-адресов и портов

🛡️ UFW интеграция — полная совместимость с UFW

⏰ Автоматическое обновление — ежедневное обновление списков через cron

📊 Статистика — просмотр количества блокировок и размера списков

📝 Логирование — подробные логи всех событий

🗑️ Гибкое удаление — частичное или полное удаление программы

## Установка
### Способ 1: Прямая установка (рекомендуемый)
```bash
curl -sSL https://raw.githubusercontent.com/Balbuto/RCN/main/rkn-watcher.sh | sudo bash
```
### Способ 2: Установка из репозитория
```bash
git clone https://github.com/Balbuto/RCN.git
cd RCN
chmod +x rkn-watcher.sh
sudo ./rkn-watcher.sh
```
### Способ 3: Ручная установка
```bash
wget https://raw.githubusercontent.com/Balbuto/RCN/main/rkn-watcher.sh
chmod +x rkn-watcher.sh
sudo ./rkn-watcher.sh
```
## Процесс установки
При запуске установки вам будет предложено:

1. Выбрать порты для фильтрации:
2. Фильтрация на одном порту (например, 443)
3. Фильтрация на нескольких портах (например, 80,443,8080)
4. Фильтрация для всех портов
5. Включить логирование RST-пакетов (рекомендуется для отладки)
6. Настроить интеграцию с UFW (если UFW используется)
7. Включить автоматическое обновление (ежедневно в 3:00)


После завершения установки будет создана команда **rkn-watcher** для управления системой.

### Быстрый старт
Запуск программы
```bash
sudo rkn-watcher
```

### Основное меню
```text
═══════════════════════════════════════════════════════════════
              RKN WATCHER - ЗАЩИТА ОТ ТСПУ И GEOIP
═══════════════════════════════════════════════════════════════

1) Управление блокировками (TSPUBLOCK + GOVIPS)
2) Настройка GeoIP фильтрации
3) Настройка UFW (интеграция)
4) Настройка расписания обновлений
5) Ручное обновление списков
6) Просмотр статистики
7) Просмотр логов
8) Удаление (частичное или полное)
9) Переустановка
0) Выход
```
### Управление демоном
```bash
sudo systemctl status rkn-watcher   # Статус демона
sudo systemctl restart rkn-watcher  # Перезапуск демона
sudo systemctl stop rkn-watcher     # Остановка демона
sudo systemctl start rkn-watcher    # Запуск демона
```
### Управление блокировками
Меню управления блокировками позволяет включать/отключать различные компоненты защиты.

**Доступные опции**

1) Включить/отключить TSPUBLOCK	Блокировка подсетей CyberOK Skipa
2) Включить/отключить GOVIPS	Блокировка IP госорганов РФ
3) Включить/отключить GeoIP	GeoIP фильтрация по странам
4) Изменить порты для GeoIP	Настройка портов для фильтрации
5) Показать правила iptables	Просмотр активных правил
6) Показать статистику	Статистика блокировок

### Статистика блокировок
Статистика показывает:

* Количество пакетов, заблокированных TSPUBLOCK
* Количество пакетов, заблокированных GOVIPS
* Количество пакетов, заблокированных GeoIP
* Размер загруженных списков подсетей


### Настройка GeoIP фильтрации
GeoIP фильтрация позволяет создать белый список стран, IP-адресов и портов.

**Доступные операции**

1) Добавить страну	Добавление страны в белый список
2) Удалить страну	Удаление страны из белого списка
3) Показать список стран	Просмотр разрешённых стран
4) Добавить IP	Добавление IP/подсети в белый список
5) Удалить IP	Удаление IP из белого списка
6) Добавить порт	Добавление порта в белый список
7) Удалить порт	Удаление порта из белого списка
8) Показать весь список	Просмотр всего белого списка
9) Вкл/Выкл GeoIP	Включение/отключение фильтрации

### Примеры добавления IP и подсетей
```bash
# Одиночный IP
```

### Интеграция с UFW
RKN Watcher полностью интегрируется с UFW, добавляя свои правила в начало цепочки.

**Доступные опции**

1) Интегрировать правила	Добавление правил RKN Watcher в UFW
2) Настроить базовые правила	Настройка SSH, HTTP, HTTPS
3) Добавить правило	Добавление пользовательского правила
4) Удалить правило	Удаление правила по номеру
5) Показать статус UFW	Просмотр текущих правил
6) Вкл/Выкл UFW	Включение/выключение UFW
7) Удалить интеграцию	Удаление правил RKN Watcher из UFW

**Примеры добавления правил UFW**
```bash
# Разрешить порт TCP
ufw allow 8080/tcp

# Разрешить порт UDP
ufw allow 53/udp

# Разрешить IP
ufw allow from 192.168.1.100

# Заблокировать IP
ufw deny from 10.0.0.1
```
### Расписание обновлений
Система поддерживает автоматическое обновление списков через cron.

**Доступные опции**

1) Показать задания	Просмотр текущих заданий cron
2) Изменить время	Изменение времени обновления
3) Вкл/Выкл автообновление	Включение/отключение автоматического обновления
4) Добавить задание	Добавление дополнительного задания
5) Удалить все задания	Удаление всех заданий RKN Watcher

### Формат расписания
```text
минуты часы день месяц день_недели

Примеры:

0 3 * * * — ежедневно в 3:00

*/30 * * * * — каждые 30 минут

0 3,15 * * * — в 3:00 и 15:00

0 3 * * 1 — каждый понедельник в 3:00
```
### Статистика и логи
Просмотр статистики
**Статистика показывает:**

* Количество заблокированных пакетов по каждому типу
* Размер загруженных списков
* Дату последнего обновления

### Типы логов

/var/log/rkn-watcher/update.log	Процесс обновления списков

/var/log/rkn-watcher/geoip.log	События GeoIP фильтрации

/var/log/rkn-watcher/watcher.log	Работа фонового демона

/var/log/kern.log	Блокировки RST-пакетов

### Просмотр логов в реальном времени
```bash
# Логи обновлений
tail -f /var/log/rkn-watcher/update.log

# Логи GeoIP
tail -f /var/log/rkn-watcher/geoip.log

# Логи демона
tail -f /var/log/rkn-watcher/watcher.log

# Системные логи (только блокировки)
grep "TSPUBLOCK\|GOVBLOCK" /var/log/kern.log | tail -20
```
### Удаление
Типы удаления

**Частичное удаление (сохраняется основной скрипт):**

* Удаляются правила iptables и ipset
* Удаляется виртуальное окружение
* Удаляются конфигурация и логи
* Удаляется сервис и задания cron
* Удаляются вспомогательные скрипты
* Сохраняется: /opt/rkn-watcher/rkn-watcher.sh и команда rkn-watcher


### Полное удаление (удаляется всё):

* Всё из частичного удаления
* Удаляется симлинк rkn-watcher
* Удаляется основной скрипт
* Удаляется директория /opt/rkn-watcher


### Ручное полное удаление
```bash
sudo systemctl stop rkn-watcher
sudo systemctl disable rkn-watcher
sudo rm -rf /opt/rkn-watcher
sudo rm -f /usr/local/bin/rkn-watcher /usr/bin/rkn-watcher
sudo rm -f /etc/systemd/system/rkn-watcher.service
sudo rm -f /etc/iptables/rules.v4 /etc/ipset.conf
sudo systemctl daemon-reload
```

### Устранение неполадок
**Проблема: Команда rkn-watcher не найдена**

Решение:

```bash
# Создать симлинк вручную
sudo ln -sf /opt/rkn-watcher/rkn-watcher.sh /usr/local/bin/rkn-watcher
```
**Проблема: Не загружаются списки**
Решение:

```bash
# Проверить интернет-соединение
ping -c 4 github.com

# Проверить DNS
nslookup github.com

# Запустить обновление вручную
sudo /opt/rkn-watcher/update.sh
```
**Проблема: Конфликт с UFW**
Решение:

```bash
# Отключить интеграцию
sudo rkn-watcher
# Выбрать: 3) Настройка UFW -> 7) Удалить интеграцию

# Или отключить UFW временно
sudo ufw disable
```
**Проблема: Ошибка "ipset: No memory available"**
Решение:

```bash
# Увеличить лимиты
echo "net.netfilter.nf_conntrack_max = 1048576" >> /etc/sysctl.conf
sysctl -p
```
**Просмотр отладочной информации**
```bash
# Показать все правила iptables
sudo iptables -L -v -n

# Показать ipset списки
sudo ipset list

# Проверить статус демона
sudo systemctl status rkn-watcher

# Показать последние ошибки
sudo journalctl -u rkn-watcher -n 50
```

### Часто задаваемые вопросы
**Вопрос:** Будет ли работать на других дистрибутивах?

**Ответ:** Скрипт разработан для Debian/Ubuntu. Для других дистрибутивов требуется адаптация команд apt и путей к конфигурационным файлам.

**Вопрос:** Как часто обновляются списки?

**Ответ:** По умолчанию ежедневно в 3:00. Вы можете изменить расписание в меню **"Настройка расписания обновлений"**.

**Вопрос:** Можно ли использовать без UFW?

**Ответ:** Да, UFW — опциональный компонент. Вы можете пропустить интеграцию при установке.

**Вопрос:** Как проверить, что блокировка работает?

**Ответ:**

```bash
# Проверить правила
sudo iptables -L TSPUBLOCK -v -n
sudo iptables -L GOVBLOCK -v -n

# Посмотреть статистику
sudo rkn-watcher -> пункт 6
```
**Вопрос:** Что делать при ошибке "Permission denied"?

**Ответ:** Все команды должны выполняться с правами root. Используйте sudo.

**Вопрос:** Как восстановить правила после перезагрузки?

**Ответ:** Скрипт автоматически создаёт скрипт восстановления /etc/network/if-pre-up.d/iptables_restore, который восстанавливает правила при загрузке системы.

**Вопрос:** Можно ли добавить свои подсети для блокировки?

**Ответ:** Да, через настройку GeoIP фильтрации можно добавить IP и подсети в белый или чёрный список.
