## 🔐 Примеры исправленных ошибок

### Shell-инъекция
```bash
# v1.0 - УЯЗВИМО
add_country() {
    read -p "Введите код страны: " country
    "$VENV_DIR/bin/python3" -c "
if '$country' not in data['countries']:  # ← ИНЪЕКЦИЯ!
"

# Атака: country="'; malicious_code #"
# → Выполнится malicious_code!

# v2.0 - ЗАЩИЩЕНО
add_country_safe() {
    local country=$1
    if ! validate_country_code "$country"; then
        return 1
    fi
    "$VENV_DIR/bin/python3" -c "
import sys
country_code = sys.argv[1]  # ← Параметр, не встраивание
" "$country"  # ← Безопасно
}
```

### Гонка в демоне
```python
# v1.0 - МОЖЕТ ЗАПУСТИТЬСЯ ДВАЖДЫ
if current_hour == 3:  # Проверяется каждые 30 сек в 3:00-3:59
    check_updates()     # → Может запуститься до 12 раз!

# v2.0 - ЗАЩИТА ОТ ДВОЙНОГО ЗАПУСКА
if current_time.hour == 3 and (current_time - last_update_time).days >= 1:
    # Проверяется: ровно 3 часа И прошло >= 1 дня
    # → Запустится ровно один раз в день
    check_updates()
```

## 🐞 Баг-репорты

Если нашли баг:
1. Проверьте логи: `/var/log/rkn-watcher/`
2. Запустите синтаксис: `bash -n rkn-watcher-fixed.sh`
3. Перезагрузите демон: `sudo systemctl restart rkn-watcher`
4. Проверьте права: `sudo whoami` (должно быть `root`)
