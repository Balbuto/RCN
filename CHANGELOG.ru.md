# Changelog

## v3.1.0 — 2026-08-09

### Исправления
- параллельные вызовы `config_tool.py` больше не теряют изменения: один lock теперь покрывает весь цикл чтения, изменения и записи конфигурации;
- legacy-значения boolean нормализуются безопасно, поэтому строка `"false"` не включает GeoIP по ошибке;
- IPv6-адреса и сети отклоняются до передачи в IPv4-only `ipset`, поэтому применение правил не падает на несовместимом вводе;
- `SHA256SUMS` пересоздан: он покрывает все tracked-файлы релиза и больше не ссылается на отсутствующие файлы.

### Документация и проверка
- документация по релизу, установке, конфигурации, безопасности, миграции, диагностике, тестам и публикации обновлена для v3.1;
- проверка контрольных сумм добавлена в GitHub Actions и в checklist публикации;
- добавлены mock-тесты параллельной записи конфигурации, нормализации boolean и отклонения IPv6.

## v3.0.0

### Исправления
- убран баг, из-за которого `setup_*` очищал уже загруженные `ipset`-списки;
- обновление `TSPUBLOCK` и `GOVIPS` переведено на атомарную схему `temp set + swap`;
- ошибки параллельной загрузки перестали маскироваться как успешный результат;
- исправлен баг, при котором update мог возвращать успех даже при неудачной загрузке списков;
- удалено дублирование `INPUT -> GEOIP` правил;
- исключены небезопасные inline-вставки пользовательского ввода в Python-код;
- uninstall больше не удаляет глобальные `/etc/ipset.conf` и `/etc/iptables/rules.v4`.

### Архитектурные изменения
- вместо `cron + daemon` используется только `systemd timer`;
- helper-логика вынесена в отдельные файлы `config_tool.py` и `geoip_apply.py`;
- добавлен отдельный интерактивный установщик `installer.sh`;
- убрана зависимость от `venv`;
- восстановление правил после перезагрузки выполняется через `systemd oneshot` сервис.

### Функциональные изменения
- GeoIP по странам теперь реально применяет country CIDR;
- добавлены allow/deny IP и allow/deny ports;
- конфиги редактируются через file lock и atomic write;
- входные данные валидируются через Python `ipaddress` и строгую проверку портов.

### Ограничения
- country-based GeoIP работает только для IPv4;
- для country filtering используется внешний источник country CIDR (`ipdeny`).
